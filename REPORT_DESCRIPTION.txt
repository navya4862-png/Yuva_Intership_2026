This report presents my Week 1 data science project on data acquisition, cleaning, preprocessing, and exploratory data analysis using the Titanic passenger dataset. I selected the Titanic dataset because it is a publicly available, well-structured beginner-friendly dataset that contains numerical and categorical variables, missing values, and a meaningful target variable. These characteristics make it suitable for demonstrating a complete data preparation workflow.

The project begins with acquisition of the dataset from a public source and documents the loading process using Python and Pandas. I then inspected the dataset dimensions, columns, data types, missing-value counts, duplicate records, and descriptive statistics. The cleaning stage included checking and removing exact duplicate records, converting numerical fields to appropriate numeric data types, and handling missing observations. Median imputation was selected for numerical variables such as Age and Fare because the median is less sensitive to extreme values. Missing Embarked values were replaced with the mode because the field is categorical and has only a small amount of missing data. Missing Deck values were represented as “Unknown” instead of assigning an unsupported value, preserving the information that the original cabin/deck value was unavailable.

For exploratory analysis, I created multiple visualizations covering missing values, survival by sex, survival by passenger class, age distribution, and the relationship between age and fare. The analysis identified clear differences in survival rates between female and male passengers and across passenger classes. I also created Family Size and Is Alone features to support future analysis.

The submitted report includes the methodology, cleaning rationale, Python code examples, visualizations, findings, limitations, reproducibility information, and references. The accompanying project package contains the raw dataset, cleaned dataset, source code, visualizations, and requirements file.
